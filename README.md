## 🚀 Proyectos destacados

### 🎙️ [NoticIA](https://github.com/JoaquinJBG/NoticIA) — podcast diario generado con IA
Pipeline automatizado que convierte la actualidad en una tertulia entre dos locutores
y publica un MP3 cada día.
- Ingesta RSS por categorías → selección → guion con LLM → locución TTS → montaje y masterizado.
- Varios motores de voz (edge-tts, Kokoro, Chatterbox) con selección automática según GPU.
- Masterizado con `ffmpeg loudnorm`, feed RSS propio, orquestador idempotente con bloqueo.

`Python` `LLM` `TTS` `ffmpeg` `pydantic` `pytest` `uv`

### 🥊 [FightLab Pro](https://github.com/JoaquinJBG/FightLab_PRO) — plataforma para atletas de combate
PWA mobile-first que une ciencia del entrenamiento, nutrición periodizada y un coach con IA.
- Motor de carga fisiológica (sRPE, monotonía, ACWR) para prevenir lesiones.
- Coach con Claude: rutinas, dietas y cálculo de kcal a partir de una foto del plato.
- Arquitectura BFF: Next.js hace de proxy y guarda los JWT en cookies `httpOnly`.

`Django 5` `DRF` `JWT` `Next.js` `TypeScript` `PostgreSQL` `Docker`

### ⚡ [Pokémon Team Builder](https://github.com/JoaquinJBG/PokemonTeamBuilder) — pokédex y constructor de equipos
Aplicación full stack con pokédex y un constructor de equipos inspirado en Showdown,
con foco en la experiencia visual.

`Angular` `TypeScript` `Spring Boot` `Java` `SQL`
